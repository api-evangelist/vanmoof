# VanMoof

> VanMoof is an Amsterdam-based e-bike company that designs and sells smart electric city bikes with integrated anti-theft technology, GPS tracking, and a companion rider app. VanMoof publishes no public developer API: the app/bike API is private, and the client libraries that exist are community-built and reverse-engineered.

Generated by API Evangelist from the VanMoof profile in the API Evangelist network (no provider-published llms.txt was found at https://www.vanmoof.com/llms.txt as of 2026-07-21).

## APIs

- No public developer API is published. Community reverse-engineered libraries exist (pymoof on PyPI; vanmoof-webapi.js and vanbike-lib on npm) but are not first-party and are not endorsed by VanMoof.
